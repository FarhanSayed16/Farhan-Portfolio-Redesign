# Game asset spec — Option B (NES SMB look)

Art lives as PNGs under `public/game/sprites|tilesets|backgrounds` (2× NES, nearest-neighbor). Generated by `scripts/gen-smb-assets.mjs`.

## Texture keys (Phaser)

| Key | Size | File |
|-----|------|------|
| `mario_s_idle`, `mario_small_walk1/2`, `mario_small_jump`, `mario_s_die` | 32×32 | `sprites/` |
| `mario_b_*`, `mario_big_*`, `mario_f_*` | 32×48 | `sprites/` |
| `goomba_0`, `goomba_walk2`, `goomba_flat` | 32×32 | `sprites/` |
| `koopa_0/1`, `koopa_shell` | 32×32 | `sprites/` |
| `mushroom`, `fireflower`, `coin_*`, `axe` | 32×32 | `sprites/` |
| `fireball`, `fireball_1` | 16×16 | `sprites/` |
| `bowser` | 64×64 | `sprites/` |
| `tiles` | 128×32 | `sprites/tiles.png` (+ `tilesets/overworld.png`) |
| `pipe`, `pipe_top`, `pipe_body` | 64×64 / 64×32 | `sprites/` |
| `bush`, `cloud`, `hill` | scenery | `sprites/` + `backgrounds/` |
| `flagpole`, `flag` | 32×32 | `sprites/` |

## Audio

| Key | Path |
|-----|------|
| SFX | `public/sounds/smb_*.mp3` |
| BGM overworld / castle | `public/game/audio/overworld.wav`, `castle.wav` |

## Controls

| Action | Desktop | Nokia pad |
|--------|---------|-----------|
| Move / Jump / Run | arrows / Space / Shift | pad |
| Fireball (fire suit) | Ctrl | RUN while fire |

## Rebuild

```bash
node scripts/gen-smb-assets.mjs
node scripts/gen-smb-bgm.mjs
```
